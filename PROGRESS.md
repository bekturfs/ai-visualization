## Правила, которые нельзя нарушать

1. `npm run build` (`tsc -b && vite build`) проходит чисто **до** каждого коммита.
   `noUnusedLocals` / `noUnusedParameters` включены — неиспользованный параметр ломает сборку.
2. Никаких ассетов: ни картинок, ни звуковых файлов, ни моделей, ни шрифтов. Текстуры
   рисуются в canvas, звук синтезируется.
3. Новых runtime-зависимостей не добавляем. Bloom — `three/addons/postprocessing/*`.
4. Модули игры импортируют только из `types.ts` / `config.ts` / `rng.ts` / `road.ts` /
   `num.ts`. Стыкуются они только в `src/Ride.tsx`.
5. Пуш только в `claude/instagram-reel-review-plcthz`, через `git push -u origin <branch>`.

## Что осталось честно недоделанным

Ничего из этого не мешает играть, но знать надо:

1. **Производительность на настоящей видеокарте не проверена.** В контейнере нет
   GPU, всё рисует SwiftShader: 3 fps на качестве 2 и 2 fps на мобильном
   портрете. Это ничего не говорит о реальном железе, но и не подтверждает, что
   там всё хорошо. Первое, что стоит сделать на машине с GPU, — открыть игру и
   посмотреть частоту кадров на всех трёх пресетах.
2. **Звук ни разу не был услышан.** В headless нет звукового устройства. Код
   синтеза компилируется, не падает и не сыплет ошибок в консоль, но что он
   звучит как задумано — непроверенное утверждение.
3. **У горизонта остался слабый тёплый налёт** от bloom тёплых огней городка.
   Заметно меньше, чем было, и отчасти похоже на засветку от города, но если
   захочется чище — поднимать `bloomThreshold` дальше.

Закрыто с прошлого раза: главы неба проверены по-настоящему (`npm run soak`
показывает 0 → 1 → … → 11 за 65 км), физика больше не зависит от частоты кадров,
мёртвый `COLORS.trunk` убран.

- Добавлен `npm run soak` — прогон логики в node через esbuild, без браузера.
  Он сразу нашёл то, чего не видно на скриншотах: **физика зависела от частоты
  кадров**. Явный Эйлер с квадратичным сопротивлением давал за пять минут 16784 м

  монитора. `step` теперь накапливает время и крутит симуляцию фиксированным

  результат (0.00 м на 15.5 км). Оставшиеся 1.46 % с автопилотом — это частота
  опроса ввода, она равна частоте кадров в любой игре.
- Тот же прогон подтвердил то, что раньше было непроверенным: главы неба идут
  подряд 0 → 1 → … → 11 за 65 км, час езды (195 км) не рождает ни одного NaN,
